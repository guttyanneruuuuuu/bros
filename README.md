# BROS — 3vs3 ケイドロ・シューティング

Brawl Stars ライクな、スマホブラウザで動作する 2D 見下ろし型チーム対戦アクションゲーム。
画像・音声アセットを使わず、プリミティブ図形のみで構成したプロトタイプ実装です。

## ゲーム概要

警察チーム（赤・3人）と泥棒チーム（青・3人）に分かれて戦うチーム対戦ゲーム。

- **泥棒チーム（青）**：マップ上のお宝（黄色い円）を集め、制限時間まで逃げ切る／一定数確保する
- **警察チーム（赤）**：泥棒を撃って HP を 0 にし逮捕、お宝を奪い返す
- **リスポーン**：泥棒は撃たれるとお宝を落とし、数秒後に自陣から復活

## 操作方法（スマホタッチ対応）

- **左スティック**：移動（360°）
- **右スティック**：エイム＆射撃。スワイプで射線表示、離すと発射
- PC ではマウスでスティックを操作可能

## マップギミック

- **障害物（灰色ブロック）**：弾・キャラが通過不可
- **茂み（緑エリア）**：中にいると敵から見えなくなる（半透明化）

## キャラクター

| | 移動速度 | HP | 射撃 |
|---|---|---|---|
| 泥棒（青） | 速い | 低い | スタンガン（命中で警察が数秒行動不能） |
| 警察（赤） | 普通 | 高い | 実弾（命中で泥棒の HP 減少） |

## ゲームモード

- **Bot 対戦（ソロ）**：味方・敵を AI が操作
- **友達対戦（ルーム）**：ローカル多人数 / Bot 補完（実装予定）

## 動かし方

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## ファイル構成

```
index.html      # 画面構造（HUD・メニュー・モーダル）
style.css       # スタイル（Brawl Stars 風UI）
js/utils.js     # 共通ユーティリティ（衝突判定など）
js/game.js      # ゲーム本体（ループ・状態管理・描画）
js/main.js      # エントリポイント・メニュー制御
```
